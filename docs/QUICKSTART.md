# 开始使用 Py妮 0.1.0

1. 将 Windows 压缩包完整解压，双击 `PyNi.exe`。不要单独移动 EXE，要保留旁边的 `_internal` 文件夹。无需安装 Python。
2. 选择“继续我的基础课”，从 print 开始。右侧写代码，点击“检查本课练习”，通过后做理解小测。五节课可离线完成。
3. 想向 AI 提问时打开“设置”，选 DeepSeek、OpenAI 或自定义服务，填入自己的 API Key、模型名称和地址。先测试连接，再保存。每次重启需重新输入密钥。
4. 可选点击“检测工具调用”。通过后启用 Agent，可查询学习进度、静态检查发送时的练习代码。此模式整段显示回复；未启用时可以流式问答。
5. 想让 Py妮阅读项目，点击“授权代码文件夹”，确认要发送给当前服务的范围。然后问“看看这个文件夹里有哪些 Python 文件”或指定文件名。仅支持 UTF-8 的 .py、.md、.rst、.txt，每文件最多 32 KB。隐藏文件、链接和常见敏感文件名被排除，但仍需自行移除代码里的秘密。
6. 提问框 Enter 换行、Ctrl+Enter 发送；右侧 Tab 插入四个空格，冒号后回车自动缩进。回答可复制或展开查看。
7. “学习记录”可以查看完成依据和填写自评；“备份学习记录”导出所有五课的草稿、问题、对话和进度。“恢复学习记录”会先校验，再经确认替换当前记录。

课程检查只识别任务要求的基础写法。Py妮不运行用户代码，也不修改项目文件。正确的其他写法可以通过“代码求助”讨论。AI 回复不是运行结果，学习完成也不代表全面掌握。

学习记录通常保存在 `%LOCALAPPDATA%\PyNi\PyNi\study.sqlite3`；配置位于 Qt 的应用配置目录。API Key 只留在本次运行内存。备份包含你输入的学习内容，不要把备份上传到公开仓库。

没有回复时先看对话框下的错误：检查密钥、额度、模型 ID 和地址；不支持流式的接口可关闭流式后重测。请求可取消，最多等待 120 秒，失败后输入仍保留。工具调用每个问题最多 4 轮、8 次。取消文件夹授权也会取消当前请求，已发给服务商的内容无法撤回。

本包未做商业代码签名。首次分发仅在开发电脑完成自动化与启动检查；建议在另一台 Windows 10/11 x64 电脑验证后正式发布。
