# Py妮

面向 Python 初学者的桌面学习助手，以基础知识为主线。

## 第一版 0.1.0

Windows 便携版：完整解压 `PyNi-0.1.0-windows-x64.zip`，双击 `PyNi.exe`，无需安装 Python。

[快速开始](docs/QUICKSTART.md) · [GitHub 发布准备](docs/GITHUB_RELEASE.md) · [更新记录](CHANGELOG.md)

## 功能

- 三栏学习空间：课程、讲解与对话、代码练习。
- 五个本地课程示例，可以切换并查看提示。
- 自动保存课程位置、各课代码草稿、未发送的问题和对话，重启后继续。
- 伙伴提示、休息与收起交互。
- DeepSeek、OpenAI、自定义服务三个模型入口，支持 Chat Completions 兼容接口。
- 真实连接测试成功后才能应用配置，可选检测工具调用格式。
- 支持流式回复、取消、120 秒总超时，以及手动重试。
- 可向模型提问或提交当前练习代码，按课程保存对话并恢复最近上下文。
- 真实 Agent 工具循环：查询学习进度、静态检查代码快照、列出和读取本次授权文件夹中的文本。
- 多行提问（Ctrl+Enter 发送）、Python 高亮、四空格 Tab 和自动缩进。
- 学习记录 JSON 备份与事务恢复；恢复前校验并确认，写入冲突时整批取消。
- 认证、模型、网络和额度错误均有中文反馈；失败时保留输入。
- 独立聊天气泡区分用户和 Py妮，回答支持 Markdown、复制、展开阅读。
- 发给模型的代码快照可以单独查看，避免每次在对话里展开整段代码。
- 教学语气以自然短段落和具体提示为主，可在 `prompts/system_prompt.txt` 调整。
- 五节基础课均提供三层提示、静态练习检查和理解小测，区分“看过示例”“提示下完成”“独立完成”。
- 学习记录可查看依据、修正状态并写备注，自行修改会明确标为“用户自评”。

**不执行用户代码、不修改项目文件。** Agent 可以调用明确开放的只读工具；AI 反馈和本地语法树检查不代表运行结果。每次最多 4 轮、8 次工具调用，总超时 120 秒，操作记录显示在回答中。
学习记录保存在本机应用数据目录的 `study.sqlite3`，不在项目仓库里；不序列化 API 配置或密钥。界面底部显示真实保存状态，失败时提醒并保留内存内容。多个窗口发生同课写入冲突时，不覆盖另一窗口的新记录。

## 第一课怎么学

1. 阅读 `print()` 的讲解，修改右侧代码，输出两行：自己的名字，以及“我开始学 Python 了”。
2. 卡住时点击提示：先给方向，再给具体提醒，第三次给参考示例。
3. 点击“检查本课练习”。本地只识别本课的两条 `print(字符串)`，不运行任意 Python。
4. 检查通过后，点击“做个理解小测”，预测两行输出并解释引号的作用。
5. 完成后记录依据和下一课建议。`独立完成`仅表示本次软件流程中没有使用提示或求助，不推断课外情况或全面掌握。

使用过本地提示、得到检查纠错、请求 AI 帮助或在理解小测答错后看过提示，会按“提示下完成”记录。修改代码后须重新检查才能继续小测。
五节课分别记录练习和小测结果，也可以通过“学习记录”自行评估。导航不强制锁课，跳到下一课不会自动标记上一课完成。
需要检查任意代码时，点击“代码求助”，再点击“请 Py妮看代码”；点击“返回课程练习”切回课程任务。

## 第二课怎么学

第二课“变量”要求自己创建 `language`，保存 `Python` 并输出；再给同一个变量赋值 `我正在学 Python`，再次输出。
本地检查关注赋值、变量名、先后顺序，以及输出的是变量还是带引号的固定文字。它只分析本课要求的四条语句，不执行程序；其他正确但超出本课范围的写法可以使用代码求助。
通过后，小测会换一个变量名，让用户预测重新赋值后的结果，并解释 `print(animal)` 和 `print("animal")` 的区别。
两课分别保存练习依据、提示使用情况和完成状态；已有第一课记录和旧版变量草稿会保留。

## 后三课怎么学

| 课程 | 练习 | 理解小测 |
| --- | --- | --- |
| 数据类型 | 对比 `age + 1` 与 `text + "1"`，分别使用整数 16 和字符串“16” | 换一组数字，预测整数相加和字符串拼接的结果 |
| 条件判断 | 使用 `age = 16` 和 `age >= 18`，保留正确的 if / else 分支 | 判断恰好达到阈值时执行哪个分支，理解 >= 的等号 |
| 循环 | 使用 `for i in range(5)`，把一条 print 放在循环内 | 预测 range(3) 的 0、1、2，以及循环外语句执行一次 |

本地检查只识别各课任务明确要求的入门写法，其他等价写法不被认定为错误，但需要通过“代码求助”讨论。检查不使用 `eval` 或 `exec`，不执行用户代码。
最后一课提供“回顾学习记录”入口。已有记录和代码草稿会保留；仅浏览或跳课不会自动标记完成。

## 连接模型

1. 在启动入口选择继续学习、直接代码求助或连接模型。打开设置后选择 DeepSeek、OpenAI 或自定义服务。
2. 在软件设置窗口输入 API Key、模型 ID 和 API 地址。预设地址和模型可以修改。
3. 点击“测试连接”。这会实际请求所选服务，可能产生少量 API 费用。
4. 测试成功后，点击“保存设置并开始”，再发送问题或提交代码。

自定义服务支持 OpenAI Chat Completions 格式，不支持任意厂商协议。远程地址必须使用 HTTPS；本机 localhost、127.0.0.1、::1 可以使用 HTTP，免认证本机服务可留空密钥。
填写基础地址（例如 `https://example.com/v1`），或完整 `/chat/completions` 地址均可。如果服务不支持流式输出，取消相应勾选再测试。

密钥仅保留在内存，每次重启需重新填写；不要把真实密钥写入源代码或粘贴进对话。
非敏感设置使用 Qt 的应用配置目录保存为 `model.json`（Windows 通常位于 `%LOCALAPPDATA%/PyNi/PyNi/`），不进入项目仓库。
连接测试只发送测试文本；正常提问或代码检查会发送当前课的目标、练习任务、右侧代码和本课最近最多六轮成功对话（历史正文最多 40000 字符）。
切换服务后，后续请求使用新的服务；不会自动重新发送失败请求。“重试”使用上次失败时的问题与代码快照。

可选的工具检测验证模型返回的调用格式，通过后在当前会话启用实际 Agent 工具。检测失败仍可使用已验证的基础问答。工具模式使用非流式完整参数与回复；基础问答保留流式输出。

点击“授权代码文件夹”并确认后，模型才可按需列出和读取其中的 `.py`、`.md`、`.rst`、`.txt`。每文件最多 32 KB，目录最多列出 100 个文件、3 层子目录，跳过隐藏文件、链接和常见敏感文件名。请自行移除代码内的密钥等私人内容；内容会交给所选服务商，过滤文件名并不等于识别所有秘密。授权不会跨重启保留，随时可撤销。工具不执行代码，也不会自动标记课程完成。

## Windows 运行

源码运行需要 Python 3.12 或更新版本，推荐 3.13。在项目目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

安装好依赖后，可以双击 `start.bat`。

## 从哪里读代码

1. `main.py`：创建 QApplication、显示窗口、进入事件循环。
2. `ui/main_window.py`：组织界面，连接按钮与处理函数。
3. `ui/lessons.py`：本地课程示例。
4. `ui/style.qss`：颜色、字体、边距和按钮样式。
5. `ui/settings_dialog.py`：填写配置、测试连接、应用设置。
6. `services/chat_client.py`：异步网络请求、流式解析与错误处理。
7. `config.py`：服务商预设、地址校验、非敏感配置保存。
8. `prompts/system_prompt.txt`：教学角色和回答原则。
9. `ui/chat_view.py`：聊天气泡、Markdown 正文与展开阅读窗口。
10. `services/learning.py`：五课静态检查、分层提示、小测内容和学习状态。
11. `services/study_store.py`：本机学习记录、事务保存和并发版本校验。
12. `ui/learning_dialogs.py`：理解小测与可修正的学习记录。

## 测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试使用本机临时 HTTP 服务和假密钥，不访问付费 API。覆盖流式分片、非流式、错误、取消、超时、禁止重定向、配置失效、对话上下文与失败重试。
真实服务的可用性、余额及模型权限，需要使用你自己的密钥在软件内测试。

`services/agent.py` 实现多轮工具调用；`tools/project_tools.py` 实现授权目录访问边界。
`requirements.txt` 是运行依赖，`requirements-dev.txt` 包含构建工具，`scripts/build_release.py` 生成便携版与干净源码包。

自动测试不代替真实服务联调和其他电脑上的安装验证；当前 Windows 包未签名。项目源码许可证待作者选择，[第三方许可](docs/THIRD_PARTY.md)另行列出。

界面框架参考：[Qt for Python 官方入门文档](https://doc.qt.io/qtforpython-6/gettingstarted.html)。

接口参考：[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[OpenAI 流式回复](https://developers.openai.com/api/docs/guides/streaming-responses)、[DeepSeek API](https://api-docs.deepseek.com/)、[DeepSeek 模型清单](https://api-docs.deepseek.com/quick_start/pricing/)。预设模型可用性以服务商账号权限为准，可手动修改。
